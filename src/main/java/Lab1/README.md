# Package

This lab exercise is for practicing version control
with git on Github with intelliJ IDEA.

## Files
- **myLibrary.Java** - contains two functions:
  - Power - calculates number raised to a Power
  - factorial - calculates factorial of a number
- **mainApp1.java** – the main executable class that calls methods from `myLibrary` and prints the results

## Purpose

This exercise walks through:
- Creating a Java Maven project in IntelliJ
- Setting up a local Git repository and making commits
- Pushing to a remote GitHub repository
